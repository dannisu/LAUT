# Versioned framework

The canonical proposed framework is packaged at
[`src/laut/resources/laut-sea-v0.1.0.toml`](../src/laut/resources/laut-sea-v0.1.0.toml).

Create an editable project copy with:

```console
laut init-config my-evaluation
```

Do not silently change thresholds. Increment the framework version, record the
calibration dataset and period, and explain the scientific reason in the pull request.
